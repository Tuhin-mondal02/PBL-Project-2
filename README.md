# PBL Project 2 – Predicting Video Games Sales

## Project Overview
This project focuses on predicting video game sales using Machine Learning techniques. It analyzes historical video game sales data to identify market trends and factors influencing sales performance.

## Objectives
- Analyze historical video game sales data.
- Perform data cleaning and preprocessing.
- Identify factors affecting video game sales.
- Develop a Machine Learning prediction model.
- Evaluate model performance and visualize results.

## Technologies Used
- Python
- Google Colab
- Machine Learning
- Jupyter Notebook
- GitHub

## Dataset
The project uses a video game sales dataset containing information related to video games, platforms, genres, publishers, ratings, and regional and global sales.

## Project Workflow
1. Dataset Collection
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Selection
5. Model Training
6. Model Evaluation
7. Sales Prediction and Visualization

## How to Run
1. Download or clone this repository.
2. Open `predicting-video-games-sales.ipynb` in Google Colab.
3. Upload the required CSV dataset.
4. Update the dataset file path if necessary.
5. Run all notebook cells sequentially.
6. View the prediction results and visualizations.
